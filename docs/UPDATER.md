# Обновления внутри приложения

Экран: **Настройки → Telegram You → Обновления** (`TgYouUpdateActivity`). Логика — `com.tgyou.update.Updater`.

## Как это работает

1. `check`: `GET https://api.github.com/repos/Gl1ch5/TgYou/releases?per_page=10`. Берётся первый релиз, который не черновик и содержит файл `*.apk` (пререлизы учитываются).
2. Сравнение: тег релиза сравнивается с `BuildConfig.TG_RELEASE_TAG`. Он подставляется при сборке из `inputs.release_tag` workflow `build-beta.yml`. Для сборок из ветки он пустой, и любой релиз считается новым. Совпадение — «последняя версия».
3. `download`: APK скачивается в `files/cache/tgyou-update.apk` с процентами, пока идёт работа; кнопка блокируется.
4. `install`: если нет разрешения «Установка из неизвестных источников», открываются системные настройки для пакета. Иначе APK передаётся системному установщику через `FileProvider` (`<applicationId>.provider`, путь `files/cache/`).

Данные чатов сохраняются, если подпись APK совпадает с установленной. Подпись сборок CI должна оставаться одной и той же ключевой парой.

## Ограничения

- Проверка идёт только при открытии экрана; фоновой проверки и уведомления на главном экране пока нет.
- Хеш APK не сверяется (GitHub отдаёт файл по HTTPS). Подпись проверяет сам Android при установке.
- Для публичного репозитория запросы не требуют токена; лимит GitHub — 60 запросов в час на IP.

## Автообновление
`UpdateManager` проверяет релизы при выходе приложения на передний план и затем раз в минуту (запросы с ETag: ответ 304 не расходует лимит GitHub). Найдя новый тег, показывает карточку сверху (`UpdateDialog`: changelog, «Установить»/«Позже»). Кнопка «Установить» скачивает APK и открывает системный установщик; у поиска в списке чатов появляется круглый индикатор загрузки (`UpdateIndicator`), нажатие по нему запускает скачивание или установку. Сборки из ветки без тега не беспокоятся. Статус: скомпилировано, на устройстве не проверено.
