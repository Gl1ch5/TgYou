# Моды

Мод — Python-плагин (Chaquopy 17, Python 3.13) в файле **`.mod`** (это ZIP с другим расширением; обычный `.zip` тоже принимается): `manifest.json` + `main.py` с функцией `on_load(api)`.
Полный доступ к приложению, без песочницы и разрешений.

Окно «Моды» (TgYou → Моды): вкладки «Маркетплейс» (установить / обновить / удалить / настройки, тап — описание),
«Установленные» (вкл/выкл, настройки, удалить), «Создать мод» (документация, архив SDK для ИИ-агента, установка из ZIP).

Код: `com.tgyou.mods` (`ModManifest`, `ModStore`, `ModRuntime`, `PyMod`, `ModApi`, `ModPages`, `MarketClient`),
UI: `ui/ModsActivity`, `ui/ModPageActivity`, `ui/ModCell`. Моды лежат в `files/mods/<id>/`.
Тестовый мод `stats` (assets/mods/stats) — страница «Статистика» и пункт меню сообщения.
Справка по API и шаблон: `TMessagesProj/src/main/assets/mod-sdk/` (отдаётся кнопкой «Скачать архив для агента»).
Маркетплейс: см. MARKETPLACE.md.

## Имена в Python API
Моды вызывают `api.hook`, `api.add_page`, `api.settings_get/put` (snake_case); в Java это алиасы к `on/addPage/getString/putString`. Статус: скомпилировано, на устройстве не проверено.

## Защита от сбоев модов

- Перед запуском `on_load` мода в `tgyou_mods` пишется маркер `loading=<id>` (синхронно). Если приложение упало внутри `on_load` (в т.ч. нативный сбой Python), при следующем старте этот мод попадает в карантин: код не выполняется, в списке видна пометка «Отключён после сбоя».
- Java-исключение, в стеке которого есть `com.tgyou.mods`, `com.chaquo` или `tgyou_mod_`, помечает все моды карантином до перезапуска — приложение снова открывается.
- Карантин снимается переустановкой/перезагрузкой мода (`ModRuntime.activate`).
- Статус: скомпилировано, на устройстве не проверено.

## Мод «Liquid Glass» (маркетплейс, `liquid_glass` 1.0.0)

Включает нативный Liquid Glass Telegram (`blur3/LiquidGlassEffect`, шейдер AGSL, Android 13+) и задаёт его силу. Мод вызывает `com.tgyou.core.TgYouGlass.configure(enabled, толщина, интенсивность, индекс)`: значения запоминаются в prefs `tgyou_glass`, включается флаг `LiteMode.FLAG_LIQUID_GLASS`, а в `LiquidGlassEffect.update` параметры умножаются на выбранные множители (один вызов `TgYouGlass`). Пресеты: Мягкий / Стандарт / Сильный / Максимум.

Честно: это не «переделка всего интерфейса», а только те панели, где Telegram сам рисует стекло. Применяется при запуске приложения. Скомпилировано, на устройстве не проверено.

## Формат `.mod` и установка по тапу

- `.mod` — ZIP с `manifest.json` в корне и Python-файлом (`entry`). Определяется по содержимому, расширение нужно только для удобства.
- **Открытие файла `.mod` или `.plugin`** (файловый менеджер, мессенджер, браузер) сразу показывает диалог «Установить / Обновить «имя»?» с автором, версией, описанием и предупреждением о доступе (`ModInstall`, intent-filter VIEW в манифесте + ветка в `LaunchActivity.handleIntent`). После подтверждения мод ставится и запускается без перезапуска.
- Кнопка **«Поделиться»** на установленном моде упаковывает его в `<id>.mod` и открывает меню «Поделиться».
- Файл `.icons` распознаётся там же и уходит в диалог установки иконок.
- Статус: скомпилировано, на устройстве не проверено.

## Мод с помощью нейросети

Вкладка «Создать мод» → карточка «Мод с помощью нейросети».

- **Скопировать промпт для нейросети** — кладёт в буфер `assets/mod-sdk/AI_PROMPT.md`: полное описание формата мода, манифеста, `api`, всех хуков с сигнатурами, доступа к классам Telegram, правил надёжности, трёх рабочих примеров и строгого формата ответа. После слова «ЗАДАЧА:» пользователь дописывает, какой мод нужен.
- **Вставить мод из буфера** — читает буфер, `ModBundle.build` превращает ответ нейросети (файлы, разделённые строками `=== путь ===`, с ```-обёртками или без) в ZIP и передаёт в `ModInstall.offer` (обычный диалог установки). Если в тексте нет разделителей, байты идут как есть (например, код плагина exteraGram).
- Для надёжности `api.icon("msg_copy")` и `api.icon("copy")` теперь равнозначны.

Статус проверки: парсер `ModBundle` проверен локальным javac-тестом (обёртки, лишний текст после блока, небезопасный путь). Экран, буфер обмена и установка на устройстве НЕ проверены; качество модов от нейросети зависит от модели и не гарантируется.
