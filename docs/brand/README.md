# Фирменный знак TgYou

SVG-исходники от владельца: `tgyou_3d.svg` (объёмная), `tgyou_flat.svg` (плоская), `tgyou_mono.svg` (только значок, `currentColor`), плюс тёмные/«передний план» варианты, собранные из того же пути.

Растровые иконки лаунчера (`mipmap-*/ic_tgyou*.png`, `icon_tgyou_*foreground.png`, `icon_tgyou_mono.png`) отрендерены из этих SVG через headless Chromium. Векторный значок для интерфейса — `res/drawable/tgyou_badge.xml` (строка «TgYou» в настройках). Статус: на устройстве не проверено.
