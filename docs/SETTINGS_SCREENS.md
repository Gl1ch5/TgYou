# Экраны настроек TgYou

Все экраны собраны на одном каркасе `ui/TgYouScreen` (декларативные строки: переключатель, выбор, слайдер, ссылка, кнопка, главный переключатель с фиксацией). Значения лежат в `core/TgYouPrefs` (файл `tgyou_prefs`), ключи вида `ghost.*`, `spy.*`, `filters.*`, `basic.*`, `chats.*`, `look.*`, `custom.*`, `pill.*`. Плагины и точки врезки читают их сами; у переведённых плагинов старые поля `fields()` убраны.

**Статус проверки у всего ниже: только компиляция (workflow `Compile check` и локальный javac). На устройстве ничего не запускалось.** Подписи сделаны по скриншотам AyuGram владельца.

Вход: «Настройки TgYou», группа «Настройки» (плитки), ниже прежние «Функции по разделам», баннеры, «Моды», «Иконки», «Обновления», «Все функции».

## Режим Призрака (`ui/GhostScreen`, `plugins/GhostModePlugin`)
- Главный переключатель с 5 опциями: не читать сообщения, не читать истории, не отправлять «онлайн», не отправлять «печатает», автоматический «офлайн». Нажатие на переключатель меняет все незафиксированные опции, на остальную строку раскрывает список. Долгое нажатие на опцию фиксирует значение (`lock.<ключ>`).
- «Читать при действиях»: при отправке сообщения или реакции шлёт собственный readHistory (помечен, чтобы не отбросился).
- «Использовать отложку»: ставит `schedule_date = сейчас + 12 с` у sendMessage/sendMedia. Не проверено: как клиент обрабатывает ответ с запланированным сообщением, возможно, поведение отличается от AyuGram.
- «Отправлять без звука»: Никогда / Всегда / В режиме призрака. «Предлагать призрака для сторис»: диалог перед открытием истории (один хук в `StoryViewer.open`).

## Фильтры сообщений (`FiltersScreen`, `ListEditScreen`, `MessageFilterPlugin`, `HideBlockedPlugin`)
- Общие фильтры: подстрока без учёта регистра или регулярное выражение `re:...`. Теневой бан: сообщения выбранных пользователей скрыты везде. Переключатели: включить фильтры, общие фильтры в чатах (иначе только личные), только входящие, скрывать заблокированных. Работает через хук `MESSAGE_VISIBLE`.

## Шпион (`SpyScreen`, `AntiRecallPlugin`, `core/TgYouSpy`, `TgYouDb` версии 2)
- Сохранять удалённые, историю правок, дату чтения (таблица `reads`, показывается в меню исходящего сообщения; только с момента включения), последний онлайн (`TgYouTweaks.userStatus`).
- Сохранять вложения: подписка на `fileLoaded`, копия в `Android/data/<пакет>/files/Saved Attachments`, лимит 300 МБ...16 ГБ/∞, «Занято», очистка. Фильтр эвристический: пропускаются файлы меньше 16 КБ, стикеры, `.tgs`, `.webp`.
- Исключения: для правок работают по любому чату; для удалений только в каналах и супергруппах, потому что Telegram присылает удаление в личных чатах без указания чата.
- База: экспорт в `files/tgyou-backup.db`, импорт через выбор файла (нужен перезапуск), очистка.

## Основные (`BasicScreen`, `core/TgYouTweaks`, `core/TgYouListTweaks`)
Округление чисел, секунды (`ExactTimePlugin` под переключателем), вибрация (частично: часть вызовов обходит отключение через `FLAG_IGNORE_VIEW_SETTING`), задержка уведомлений, Zalgo (в тексте сообщений вместо удаления подставляется U+200B, чтобы не сдвигать entity; в именах удаляется), скорость загрузки/отправки (число параллельных запросов и размер куска; «Ультра» может привести к лимитам Telegram), папка сохранения, относительный онлайн, скрытие номера, «Показывать ID и DC» (Bot API для пользователей совпадает с Telegram API), архив (скрыть, открыть при подтягивании, отключить жест «Вернуть» сопоставлен со свайпом назад в списке: смысл пункта уточнить), «Не переводить» (экран Telegram).

## Чаты (`ChatsScreen`, `core/TgYouChatTweaks`)
Размер текста (10-40), размер стикеров (50-150% от стандартного), скрывать клавиатуру при прокрутке, запятая после упоминания, скрыть «Отправить как...», скрыть приветственный стикер. **Не сделано:** «Ответы», «Широкие посты», AI-функции, быстрые админ-действия, свайп-навигация, результаты вычислений. Ни в подписях, ни в коде этих пунктов нет.

## Внешний вид (`AppearanceScreen`, `PillStackScreen`, `core/TgYouPillStack`)
Скругление аватаров (хук в `ImageReceiver.setRoundRadius`: радиусы от 14 dp масштабируются; заглушка на время загрузки остаётся круглой), снег в шапке списка чатов (хук в `ActionBar.drawChild`), заголовок, скрыть истории/кнопку/поиск (на месте поиска остаётся отступ), системные эмодзи, жидкое стекло, скругление пузырей; ссылки на прежний экран прозрачности, Pill Stack, иконки, иконку приложения, тему. **Pill Stack:** таблетки в строке поиска (время, дата, заряд, память, прокси, призрак), нажатие листает по кругу, долгое открывает настройки. Погоды и курсов нет (нужны внешние сервисы). **Не сделано:** центрирование заголовка, мини-аватарки отправителей, стиль заголовков папок, счётчик на папках, скрытие «Все чаты», Material Design 3, анимация прилипающего аватара, разные темы чатов, размытие по отдельным пунктам, выбор системных шрифтов отдельным пунктом (есть мод «Шрифты»).

## Кастомизация (`CustomizationScreen`)
Предпросмотр удалённого сообщения, «Полупрозрачные удалёнки», «Метка удалёнок» (значок/текст/нет, цветовых кружков нет), метка изменённых, ссылки на Pill Stack, Режим Призрака, Основные; «Полезные функции»: локальный Premium и отключение рекламы (включают соответствующие плагины), статус призрака в заголовке списка чатов. **Не сделано:** «Фоновая работа», «Жесты».
