# Экраны настроек TgYou

Все экраны собраны на одном каркасе `ui/TgYouScreen` (декларативные строки: переключатель, выбор, слайдер, ссылка, кнопка, главный переключатель с фиксацией). Значения лежат в `core/TgYouPrefs` (файл `tgyou_prefs`), ключи вида `ghost.*`, `spy.*`, `filters.*`, `basic.*`, `chats.*`, `look.*`, `custom.*`, `pill.*`. Плагины и точки врезки читают их сами; у переведённых плагинов старые поля `fields()` убраны.

**Статус проверки у всего ниже: только компиляция (workflow `Compile check` и локальный javac). На устройстве ничего не запускалось.** Подписи сделаны по скриншотам AyuGram владельца.

Вход: «Настройки TgYou», группа «Настройки» (плитки), ниже прежние «Функции по разделам», баннеры, «Моды», «Иконки», «Обновления», «Все функции».

## Режим Призрака (`ui/GhostScreen`, `plugins/GhostModePlugin`)
- Главный переключатель с 5 опциями: не читать сообщения, не читать истории, не отправлять «онлайн», не отправлять «печатает», автоматический «офлайн». Нажатие на переключатель меняет все незафиксированные опции, на остальную строку раскрывает список. Долгое нажатие на опцию фиксирует значение (`lock.<ключ>`).
- «Читать при действиях»: при отправке сообщения или реакции шлёт собственный readHistory (помечен, чтобы не отбросился).
- «Использовать отложку»: ставит `schedule_date = сейчас + 12 с` у sendMessage/sendMedia. Не проверено: как клиент обрабатывает ответ с запланированным сообщением, возможно, поведение отличается от AyuGram.
- «Отправлять без звука»: Никогда / Всегда / В режиме призрака. «Предлагать призрака для сторис»: диалог перед открытием истории (один хук в `StoryViewer.open`).

## Фильтры сообщений (`FiltersScreen`, `ListEditScreen`, `MessageFilterPlugin`, `HideBlockedPlugin`)
- Общие фильтры: подстрока без учёта регистра или регулярное выражение `re:...`. Теневой бан: сообщения выбранных пользователей скрыты везде. Переключатели: включить фильтры, общие фильтры в чатах (иначе только личные), только входящие, скрывать заблокированных. Работает через хук `MESSAGE_VISIBLE`.

## Шпион (`SpyScreen`, `AntiRecallPlugin`, `core/TgYouSpy`, `TgYouDb` версии 2)
- Сохранять удалённые, историю правок, дату чтения (таблица `reads`, показывается в меню исходящего сообщения; только с момента включения), последний онлайн (`TgYouTweaks.userStatus`).
- Сохранять вложения: подписка на `fileLoaded`, копия в `Android/data/<пакет>/files/Saved Attachments`, лимит 300 МБ...16 ГБ/∞, «Занято», очистка. Фильтр эвристический: пропускаются файлы меньше 16 КБ, стикеры, `.tgs`, `.webp`.
- Исключения: для правок работают по любому чату; для удалений только в каналах и супергруппах, потому что Telegram присылает удаление в личных чатах без указания чата.
- База: экспорт в `files/tgyou-backup.db`, импорт через выбор файла (нужен перезапуск), очистка.

## Основные (`BasicScreen`, `core/TgYouTweaks`, `core/TgYouListTweaks`)
Округление чисел, секунды (`ExactTimePlugin` под переключателем), вибрация (частично: часть вызовов обходит отключение через `FLAG_IGNORE_VIEW_SETTING`), задержка уведомлений, Zalgo (в тексте сообщений вместо удаления подставляется U+200B, чтобы не сдвигать entity; в именах удаляется), скорость загрузки/отправки (число параллельных запросов и размер куска; «Ультра» может привести к лимитам Telegram), папка сохранения, относительный онлайн, скрытие номера, «Показывать ID и DC» (Bot API для пользователей совпадает с Telegram API), архив (скрыть, открыть при подтягивании, отключить жест «Вернуть» сопоставлен со свайпом назад в списке: смысл пункта уточнить), «Не переводить» (экран Telegram).

## Чаты (`ChatsScreen`, `core/TgYouChatTweaks`, `TgYouCalc`, `TgYouGestures`, `TgYouAi`, `plugins/ChatExtrasPlugin`)
Размер текста (10-40), размер стикеров (50-150%), скрывать клавиатуру при прокрутке, запятая после упоминания, скрыть «Отправить как...», скрыть приветственный стикер.
- **Ответы** (главный переключатель 3 пункта, по умолчанию выкл.): без подсветки при переходе, ответ без цитаты, упоминание автора (в группах подставляет @имя в пустое поле).
- **Широкие посты** (Каналы / Лента): пузырь поста шире на 56 dp; применяется к сообщениям, загруженным после включения.
- **ИИ-функции** (Редактор, Краткие сводки, Сводки в Instant View; по умолчанию вкл., как в стоке): первые два скрывают нативные кнопки Telegram. Сводка Instant View сделана пунктом меню сообщения со ссылкой и запросом к Groq (ключ из плагина «Whisper», модель настраивается).
- **Быстрые админ-действия**: пункты меню сообщения «Удалить и забанить» и «Заглушить» (1 час/1 день/7 дней/навсегда; заглушение только в супергруппах).
- **Быстрый переход свайпом**: ответ / в Избранное. **Результаты вычислений**: «2+2=» превращается в «2+2= 4» (+ - * / ^ % скобки).
- Экран «Жесты» (Кастомизация): двойное касание по чужому и своему сообщению (реакция, ответ, избранное, копирование, правка, ничего).

## Внешний вид (`AppearanceScreen`, `PillStackScreen`, `core/TgYouPillStack`, `TgYouFolders`, `TgYouMiniAvatars`, `TgYouGlass`)
Скругление аватаров, снег, заголовок, скрыть истории/кнопку, системные эмодзи, жидкое стекло, скругление пузырей, ссылки на прежние экраны, Pill Stack (таблетки в строке поиска).
- **Скрыть поиск** теперь без отступа: `DialogsActivity.SEARCH_FIELD_HEIGHT` стал нестатическим и ставится в 0 на `onResume`, возвращается в 48 на `onPause`/уничтожении (остальные экраны не затронуты).
- **Заголовок по центру**: поле `ActionBar.tgyouCenter`, только для главного списка чатов.
- **Мини-аватарки**: рисуются в `DialogCell` перед превью в группах, только в двухстрочном виде и не в RTL; в трёхстрочном виде и для каналов не показываются.
- **Папки**: стиль заголовков (иконка = эмодзи в начале названия, включая кастомные), счётчик (все / только неотключённые / откл.), скрытие «Все чаты» (ширина вкладки 0, при открытии выбирается первая папка; свайпом влево страница всё ещё открывается).
- **Material Design 3** (6 переключателей, каждый отдельно): радиус пузырей 20, тональные панель ввода / входящие пузыри / шапка / фон списков (смешивание с акцентным цветом в `Theme.getColor`), без разделителей.
- **Размытие**: обводка стекла (Блики/Нет, хук в `BlurredBackgroundDrawableRenderNode`), стеклянное меню сообщения (полупрозрачный фон), принудительное размытие (игнорирует серверный запрет в светлой/тёмной теме).
- **Различные темы в чатах** (выкл. = игнорировать темы собеседников), **липкая анимация аватарок** (выкл. = аватарка профиля не сжимается при прокрутке), **системные шрифты** (включает мод «Шрифты» с семейством «Системный», после перезапуска).
- Погоды и курсов в Pill Stack нет (нужны внешние сервисы).

## Кастомизация (`CustomizationScreen`)
Предпросмотр удалённого сообщения, «Полупрозрачные удалёнки», «Метка удалёнок» (значок/текст/нет + 8 цветовых кружков, повторное нажатие сбрасывает цвет), метка изменённых, ссылки на Жесты, Pill Stack, Режим Призрака, Основные; «Полезные функции»: локальный Premium, отключение рекламы, статус призрака. **Работать в фоне**: включает `pushService`/`keepAliveService` (штатная служба `NotificationsService`) и запрашивает исключение из оптимизации батареи (разрешение `REQUEST_IGNORE_BATTERY_OPTIMIZATIONS` добавлено в манифест); при выключении возвращает прежние значения.

## Основные: дополнение
«Показывать ID и DC» теперь и в профиле группы/канала: ID в формате Bot API (`-100…` для каналов и супергрупп, `-…` для обычных групп), DC по фото чата.

**Статус проверки: компилируется (локальная компиляция c59-c62); на устройстве не проверено.** Наиболее рискованное без проверки: скрытие «Все чаты», мини-аватарки (сдвиг текста), тональные цвета Material Design 3, центрирование заголовка.
