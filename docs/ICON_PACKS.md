# Иконпаки (`.icons`, формат exteraGram)

**Статус:** скомпилировано (локальный javac), на устройстве не проверено.

## Формат
ZIP с `metadata.json` (`packName`, `packId`, `author`, `version`, `icons: {имя_drawable: файл}`) и файлами PNG/SVG. Пакет с `manifest.json` считается модом, а не иконпаком.

## Как работает
- `com.tgyou.icons.IconPacks` — установка (распаковка в `files/iconpacks/<id>`, защита от zip-slip, лимиты 80 МБ / 3000 файлов), список, включение, удаление.
- `PackResources` — обёртка `Resources`: `getDrawable` / `getDrawableForDensity` подменяют drawable по имени ресурса на растр из пака (SVG рисуется через androidsvg, размер — как у оригинала). Без активного пака возвращаются обычные `Resources`.
- Хуки: однострочные `getResources()` в `LaunchActivity` и `ApplicationLoader`.
- UI: «Моды → Установить из файла» (`.icons` определяется сам), вкладка «Установленные» → блок «Иконпаки»: Включить / Выключить / Удалить.

## Ограничения
- Иконки применяются на новых экранах; для полного эффекта нужен перезапуск.
- Иконки, которые Telegram кэширует в статических полях (`Theme.*`), обновятся после перезапуска.
- Lottie-SVG со сложными градиентами/clipPath рисуются в пределах возможностей androidsvg.

## Установка и экран «Иконки»

- **Открытие файла `.icons`** (из файлового менеджера, мессенджера, браузера) → TgYou сразу показывает диалог с предпросмотром иконок набора и кнопками «Установить и включить» / «Только установить» / «Отмена» (`IconPackInstall`, intent-filter VIEW в манифесте + ветка в `LaunchActivity.handleIntent`).
- **Настройки TgYou → «Иконки»** (`IconPacksActivity`): плитки 2 в ряд — «Стандартные» и каждый установленный набор с миниатюрами иконок, автором и числом иконок. Тап по набору → окно с сеткой иконок и кнопками «Применить / Выключить», «Удалить». Кнопка «+» в шапке — выбрать файл `.icons`.
- Статус: скомпилировано, на устройстве не проверено. Набор применяется сразу (быстрая перезагрузка экранов, см. APPEARANCE.md).

## Сколько иконок применится
В окне пака показано «Применится N из M»: считаются иконки пака, для которых в приложении есть drawable с таким именем (у Liquid Glass Pack 862 из 1000, остальные — имена из других форков, например `ayu_*`, `filter_*`). PNG-иконки подменяются и при чтении через `openRawResource`/`BitmapFactory.decodeResource`; SVG — только через `getDrawable`. На устройстве не проверено.
