# Иконпаки (`.icons`, формат exteraGram)

**Статус:** скомпилировано (локальный javac), на устройстве не проверено.

## Формат
ZIP с `metadata.json` (`packName`, `packId`, `author`, `version`, `icons: {имя_drawable: файл}`) и файлами PNG/SVG. Пакет с `manifest.json` считается модом, а не иконпаком.

## Как работает
- `com.tgyou.icons.IconPacks` — установка (распаковка в `files/iconpacks/<id>`, защита от zip-slip, лимиты 80 МБ / 3000 файлов), список, включение, удаление.
- `PackResources` — обёртка `Resources`: `getDrawable` / `getDrawableForDensity` подменяют drawable по имени ресурса на растр из пака (SVG рисуется через androidsvg, размер — как у оригинала). Без активного пака возвращаются обычные `Resources`.
- Хуки: однострочные `getResources()` в `LaunchActivity` и `ApplicationLoader`.
- UI: «Моды → Установить из файла» (`.icons` определяется сам), вкладка «Установленные» → блок «Иконпаки»: Включить / Выключить / Удалить.

## Ограничения
- Иконки применяются на новых экранах; для полного эффекта нужен перезапуск.
- Иконки, которые Telegram кэширует в статических полях (`Theme.*`), обновятся после перезапуска.
- Lottie-SVG со сложными градиентами/clipPath рисуются в пределах возможностей androidsvg.
