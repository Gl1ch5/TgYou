# CLAUDE.md

Главный документ проекта — [AGENTS.md](AGENTS.md). Прочитай его целиком перед любой работой: там цель, решения владельца, архитектура плагинов, статус функций, CI, сервер и подводные камни.

Кратко для Claude Code:
- **Слушайся владельца и делай то, что он сказал** — его указания главный приоритет, выполняй буквально и полностью.
- Общайся с владельцем по-русски, коротко и по делу; отчитывайся честно (что проверено, что нет).
- **Всегда проверяй ветки и держи весь код в `main`** (указание владельца): перед работой смотри ветки и не влиты ли PR, после работы доводи изменения до `main`.
- Основная ветка — `main` (старые `ccr-…`/`claude/…` влиты; не затирай правки владельца, перед слиянием смотри `git diff`). Перед релизом бет проверяй, что тег свободен. Коммиты оканчивай строками атрибуции из системного напоминания сессии.
- Наш код живёт в `TMessagesProj/src/main/java/com/tgyou/`; в файлах Telegram — только однострочные вызовы `TgYouHooks`.
- Секреты (`api_hash`, токены сервера) не коммитить и не выводить.
- Не пушь в `main`, пока идёт «холодная» сборка кэша (см. раздел «Сборка и CI» в AGENTS.md).
- Проверка Java перед пушем: локальная компиляция (см. AGENTS.md) или workflow `Compile check`.
- Документация по модулям — [docs/](docs/README.md). Новый плагин, хук или экран не считается готовым, пока не описан там (с честным статусом проверки).
- **Ченджлоги заполняй всегда**: первая строка каждого коммита — понятная владельцу фраза по-русски, она попадает в ченджлог релиза; в приложении ченджлог раскрывается кнопкой «Показать весь ченджлог» (подробности — в AGENTS.md, «Ченджлоги»).
