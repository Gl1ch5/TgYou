Подмена методов приложения для продвинутых плагинов.

# плагин-подпись
from base_plugin import BasePlugin, HookResult, HookStrategy

class Signature(BasePlugin):
    def on_plugin_load(self):
        self.add_on_send_message_hook()

    def on_send_message_hook(self, account, params):
        params.message += "\n— из Telegram You"
        return HookResult(HookStrategy.MODIFY, params=params)

Вопросы

Это безопасно?

Клиент основан на открытом коде Telegram для Android. Исходники проекта открыты на GitHub, сборки делаются публично в CI.

Могут ли заблокировать аккаунт?

Telegram разрешает сторонние клиенты на открытом API. Мы не отправляем ничего, что отличает клиент от официального, кроме настроенных вами функций.

Работают ли плагины exteraGram?

Да, файлы .plugin и наборы иконок .icons устанавливаются без переделки. Покрытие совместимости описано в документации проекта.

Какие устройства поддерживаются?

Android на процессоре arm64. Версия бета, поэтому возможны ошибки — сообщайте об этом на GitHub.

Как обновляться?

Встроенный экран «Обновления» проверяет новые версии на GitHub и скачивает APK.
