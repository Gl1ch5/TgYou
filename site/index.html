Плагины на Python без песочницы.

Перехватывайте запросы, добавляйте пункты меню, меняйте интерфейс. Плагин — один файл, ставится в одно нажатие.

# пример плагина
from base_plugin import BasePlugin, HookResult, HookStrategy

class Signature(BasePlugin):
    def on_plugin_load(self):
        self.add_on_send_message_hook()

    def on_send_message_hook(self, account, params):
        params.message += "\n— отправлено из Telegram You"
        return HookResult(HookStrategy.MODIFY, params=params)
